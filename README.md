# 📈 Real-Time Stock Alert System

A Python-based stock market monitoring system that tracks multiple stocks, checks price movements, and sends automated alerts through Telegram when configured conditions are met.

The goal of this project is to reduce the need for manual stock price monitoring by delivering important price-change notifications directly to a Telegram chat.

## 🚀 Features

- **Stock Price Monitoring:** Fetches stock market data using `yfinance`.
- **Multiple Stock Tracking:** Monitors multiple configured stocks.
- **Price Change Detection:** Checks stock prices and percentage changes against configured alert conditions.
- **Telegram Notifications:** Sends stock alerts using the Telegram Bot API.
- **Automated Monitoring:** Supports repeated checks to identify relevant price movements.
- **API Integration:** Uses HTTP requests to communicate with the Telegram Bot API.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core application logic |
| `yfinance` | Fetching stock market data |
| `requests` | Making HTTP requests |
| Telegram Bot API | Delivering stock alerts |
| Environment variables | Storing configuration and API credentials |

## 🏗️ How It Works

The system follows a simple monitoring and notification workflow:

1. **Fetch market data:** Retrieve available stock price data using `yfinance`.
2. **Process stock prices:** Extract the relevant price information for each configured stock.
3. **Evaluate conditions:** Compare the retrieved data against the configured price or percentage-change thresholds.
4. **Generate alerts:** Prepare a notification when a configured condition is satisfied.
5. **Send Telegram messages:** Make an HTTP request to the Telegram Bot API to deliver the notification.
6. **Repeat monitoring:** Run the checks again according to the configured monitoring interval.

```text
       Stock Symbols
             |
             v
      yfinance API
             |
             v
      Process Prices
             |
             v
     Check Alert Rules
             |
       +-----+-----+
       |           |
   Condition     Condition
   Not Met        Met
       |           |
       v           v
   Continue    Create Alert
                   |
                   v
             Telegram Bot API
                   |
                   v
             Telegram Chat
```

## 📋 Prerequisites

Before running the project, ensure you have:

- Python 3.9 or a compatible version.
- An internet connection.
- A Telegram account.
- A Telegram bot token.
- A Telegram chat ID.
- The required Python packages.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```

Replace the placeholders with your actual repository URL and project directory.

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install yfinance requests
```

If your project uses additional packages, install those as well.

### 4. Configure Telegram

1. Open Telegram and find `@BotFather`.
2. Create a bot using `/newbot`.
3. Copy the generated bot token.
4. Obtain the chat ID of the destination chat.
5. Ensure the bot is allowed to send messages to that chat.

Keep your bot token private. Do not commit credentials to GitHub.

### 5. Configure stock symbols and alert thresholds

Set the stock symbols and the price or percentage-change conditions according to your implementation.

For example, symbols such as `AAPL` or `MSFT` can be used to monitor US-listed stocks. For Indian-listed stocks, the appropriate Yahoo Finance symbols, such as `RELIANCE.NS`, may be used.

The exact symbol format and alert rules depend on your configuration.

### 6. Run the application

Use the Python entry-point file in your repository:

```bash
python <YOUR_MAIN_FILE>.py
```

Replace the placeholder with your actual filename.
